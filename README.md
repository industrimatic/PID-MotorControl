# PID电机控制器

## 项目简介

一个简单的串级PID电机控制程序

## 硬件

- 电机减速比`30`，编码器线数`11`，
- 电驱使用TB6612FNG
- 串口，我这里用的开发板自带的DAP

## 算法

- 定时测速、定时测位
- 速度环为内环，角度环为外环

## 使用本程序

1. 使用`git clone`或直接下载将项目保存到本地
2. 使用cubemx可以查看引脚配置，使用keil可以打开工程，我本人使用vscode的keil assistant来查看代码

使用支持波形显示的软件做上位机以获取以下信息

- 当前PWM的输出
- 实测速度
- 目标速度
- 实测位置
- 目标位置
